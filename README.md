# Live-Music-Experience-Database

The Live Music Experience Database project was assigned to Fabian, Kemrick, Moises, and Valentino. Below are setup instructions and a brief description on the database.


Description:
This is a relational database with the main focus of being venues. Within the database, venues are able to host multiple artists and shows. Constraints were added to ensure data remains consistent so the person running the database can update and run queries with peace in mind.


Setup Instructions:

#1. Run the below line within PgAdmin4 to create the database.
CREATE DATABASE "LIVE MUSIC EXPERIENCE";

#2. Run the statements found on the Live Music Experience - Table and Data Insertion Statments.sql file.

#3. Run the queries found on the Live Music Experience - Queries.sql file.

#4. Run the new database utilities found on the Live Music Experience - Database Utilities.sql file.
